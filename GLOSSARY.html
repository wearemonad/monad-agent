Monad

A desktop company-brain workspace where people converse with AI agents that work over their knowledge and tools.

Conversation

Thread
The durable conversation and work history a person has with an agent, listed in the sidebar. It outlives any agent process.
Avoid: chat, conversation, session (in user-facing language)
Turn
One person-to-agent cycle within a Thread: a person's message and everything the agent does in response until it finishes.
Avoid: run, exchange, request
Session
The agent provider's runtime attached to a Thread. A Session can be stopped and resumed without affecting the Thread.
Avoid: thread (for the provider runtime), process
